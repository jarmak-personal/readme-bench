Inspired by [show me a pelican riding a bicycle](https://github.com/simonw/pelican-bicycle):
Take a repository, remove its documentation and agent-instruction files, 
and give every model the same prompt:

> Please create a README.md for this project.

The agent takes it from there, hopefully inspecting the repository with
its tools (offline), and writes the README. The README is published
exactly as produced. No scoring, just some notes as I read them.

## But why?

If you've read a README lately, you've probably read one generated by an agent.
I take no issue with using agents to build things (I'm in favor, even), but
some of these READMEs are _really bad_. I think it's because the agents
really don't have a concept of what a good README is.

To be honest, if you ask 100 people, you'll probably get 100 answers too.

## Here's what I think helps make a "good README"

READMEs represent the introduction to the project/library/whatever.
A good README, then, should (not necessarily in this order):
- Introduce the reader to the project quickly/succinctly/easily
- Tell the reader how they can use it (or why it exists)
- Tell the reader why they might find it valuable
- Explain what they need at a bare level to use it
- Provide interesting leading information about the project and links to read more

It's less of a "here's the project" and more of a "here's the raison d'être".

## A few thoughts
Yes, a better prompt would get better results. Yes, an AGENTS.md would get better
results. I don't think any of them would get _good_ results, and I was curious
what would happen if they could go off on their own and just show me what a README is.

I think in general the README examples show the gaps of agentic development well.
You've probably heard something to the effect of `taste is what you need` and
I think that's still very salient. Agents can do many things, many things you
or I cannot do. But, they face challenges with the _why_ and the big picture.
I'm curious what these READMEs will look like down the line as capabilities continue
to expand.
